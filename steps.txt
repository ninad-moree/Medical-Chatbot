1. Create a new environment: 
conda create -n medicalbot python=3.11 -y

2. Activate new environment: 
conda activate medicalbot

3. Install the required packages: 
python -m pip install --upgrade pip
python -m pip install "protobuf>=4.25.8,<7" langchain-core langchain-community langchain-huggingface langchain-pinecone langchain-google-genai sentence-transformers pinecone pypdf ipykernel

4. Register the environment with Jupyter:
python -m ipykernel install --user --name medicalbot --display-name "Python (medicalbot)"

5. Open Jupyter Notebook:
jupyter notebook
